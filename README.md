| Номер | Тип       | Къде се намира в BIN | Кратко описание                     |
|-------|-----------|----------------------|-------------------------------------|
| 0     | instance  | .data                | Обект с полета (създаден от VM)     |
| 1     | bytecode  | .text                | Главен код или блок за изпълнение   |
| 2     | int       | .data                | 32-битово цяло число (напр. 42)     |
| 3     | float     | .data                | 32-битово число с плаваща запетая   |
| 4     | string    | .data                | ASCII текст (напр. "hello")         |
| 5     | bytes     | .rodata              | Бинарни данни (напр. b"hello")      |
| 6     | list      | .rodata              | Динамичен масив от индекси          |
| 7     | tuple     | .rodata              | Неизменим масив от индекси          |
| 8     | dict      | .rodata              | Хеш масив от ключове и стойности    |
| 9     | bool      | .data                | Булева стойност (1 или 0)           |
| 10    | none      | .data                | Нулева стойност (None)              |
| 11    | function  | .text                | Байткод на функция                  |
| 12    | name      | .symtab              | Глобално име (напр. MyClass)        |
| 13    | varname   | .symtab              | Локална променлива (напр. x)        |
| 14    | class     | .rodata              | Структура с име и методи на клас    |
| 15    | module    | .modtab              | Име на модул (напр. "main")         |
| 16    | builtin   | .data                | Индекс на вградена функция (print)  |
